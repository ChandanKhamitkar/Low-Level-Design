- Adapter is a structural design pattern that allows objects with incompatible interfaces to collaborate.

- Adapter converts an incompatible interface into the interface expected by the client.

- Want to use 3rd party library, but the class it gives isn't compatible with your code, so we write adapter to that 3rd party class, so that it can easily work with our code, without chaning our core services, just bcoz of this 3rd party isn't compatible.
